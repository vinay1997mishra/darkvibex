## 1. Global visual identity

### Global app background — CURRENT RULE
- The DarkVibeX global/default app background is the **blue–purple galaxy / cosmic image** currently integrated in the app.
- This blue–purple galaxy background is the current app-wide visual shell.
- **Old references that say the DarkVibeX global background is black, dark charcoal, or black + gold are obsolete and must not be used as the current background rule.**
- Gold may still be used as a feature/premium accent where already approved, but it is **not** the global page background.
- New DarkVibeX pages, overlays, dialogs, and feature surfaces should visually blend with the blue–purple galaxy identity rather than introducing an unrelated orange/white or plain black shell.
- Existing custom room themes/backgrounds remain separate from this default/global app background where the room feature allows a user/owner-selected theme.

| Day | Reward |
|---|---:|
| Day 1 | 70,000 coins |
| Day 2 | 90,000 coins |
| Day 3 | 100,000 coins (1L) |
| Day 4 | 120,000 coins |
| Day 5 | 150,000 coins |
| Day 6 | 180,000 coins |
| Day 7 | 250,000 coins |

### Weekly sign-in UI rule
- Use the DarkVibeX **blue–purple galaxy visual identity** for the sign-in experience.
- Do not use the previously mocked orange/yellow + white theme as the final DarkVibeX design.
- The current/claimed day should have a clear claimed state.
- Day 7 may receive a stronger celebratory highlight while staying within the DarkVibeX galaxy theme.
